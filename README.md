## What it does

`main.py` writes a single original one-line roast of a smart fridge — at most 200 characters — to `/output/entry.txt`. The line targets the fridge's firmware update habit: after updating itself, it refuses to chill anything until it gets a five-star rating.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
